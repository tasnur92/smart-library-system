System Capabilities

Everything Needed for Modern Library Administration

A fully integrated web platform handling end-to-end borrowing workflows, catalog management, real-time reservations, and automated fines.

Role-Based Authentication

Secure login with Firebase Authentication and Firestore synchronization. Distinct dashboards and route protection for Admins and Students.

Comprehensive Book Management

Librarians can add, edit, and delete books with ISBN validation, duplicate prevention, category assignments, and live stock tracking.

Dynamic Search & Filtering

Instant full-text search across titles, authors, categories, and ISBNs with interactive category chips, stock filters, and sorting.

Atomic Issue & Return

Firestore transactions guarantee inventory accuracy when issuing and returning books. Automatic loan countdown and return validation.

Automated Overdue Fines

Calculates overdue fines automatically when a book passes its due date. Complete payment ledger with admin waivers and student receipts.

Smart Waitlist Reservations

Students can reserve out-of-stock titles. The moment a book is returned, the system automatically alerts the next student in line.
